# Wilfred 0.2.1

Wilfred 0.2.1 consolidates the first post-Public-Alpha
runtime and interaction foundations.

The release keeps the provider-neutral execution model of
Wilfred 0.2.0 while making predictable goal resolution and
longer-lived interactions more reusable.

## Highlights

- Deterministic-first goal resolution before optional AI
  planner fallback.
- Reusable pending-action lifecycle for interactions that
  continue beyond a single request.
- In-memory and JSON-backed pending-action persistence.
- Provider-neutral acknowledgement before potentially slow
  planner-provider fallback.
- Butler Core 0.1.4 as the shared execution and resolution
  contract foundation.
- Expanded capability-first architecture and use-case
  documentation.

## Deterministic resolution

Known requests can now be resolved through the shared Butler
Core deterministic resolution pipeline before a planner
provider is consulted.

Planner fallback remains optional and execution still passes
through the normal validation, permission and confirmation
policy.

## Pending actions

Wilfred now provides reusable pending-action primitives for
workflows that may be confirmed, snoozed, dismissed, expired
or otherwise completed later.

The public boundary includes both in-memory storage and
JSON-backed persistence with atomic replacement.

## Provider latency acknowledgement

A runtime may use the provider-neutral output contract to
acknowledge an interaction before entering a potentially slow
planner fallback.

Acknowledgement delivery is best-effort and cannot grant
execution authorization or block planning when delivery
fails.

## Capability direction

The documentation now makes the distinction between
integrations, tools, capabilities, domains and goals explicit.

Media, appliance/laundry and proactive-communication
patterns remain real-world validation areas and are not
presented as public installable Wilfred capabilities in this
release.

## Public Alpha

Wilfred 0.2.1 remains a Public Alpha.

Runtime and plugin contracts may continue to evolve while
capability and domain ownership are progressively promoted
into first-class public runtime concepts.
