# Wilfred 0.1.9

Wilfred 0.1.9 completes the standalone foundation leading to the
0.2.0 Public Alpha.

## Highlights

- provider-neutral planned execution;
- provider-neutral Goal Runtime;
- optional OpenAI BYOK planner provider;
- immediate acknowledgement before potentially slow provider calls;
- goal-oriented CLI;
- standalone HTTP API for runtime, tools and goals;
- public onboarding from installation to deterministic execution;
- shared provider-neutral output contracts from Butler Core 0.1.3.

## Output contract convergence

Wilfred no longer owns a separate copy of the provider-neutral output
contracts.

Starting with 0.1.9, `wilfred.output` exposes the contracts published by
Butler Core 0.1.3.

The shared model explicitly distinguishes an asynchronous dispatch that
has been `ACCEPTED` from a delivery that has been positively verified as
`DELIVERED`.

`OutputCapability` remains available as a temporary compatibility alias
for `OutputKind`.

## Scope

0.1.9 is intentionally a standalone foundation release.

The public Home Assistant adapter and the official Docker distribution
are planned for the 0.2.0 Public Alpha.
